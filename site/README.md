# Site vitrine PRIMAL

Site statique (HTML/CSS/JS, aucune dépendance). Ouvrir `index.html` pour le voir.

- Héberger : déposer tout le dossier `site/` sur n'importe quel hébergeur statique (GitHub Pages, Netlify, etc.).
- Nuages : générés par `tools/gen-clouds.py` (`python3 tools/gen-clouds.py site/img`).
- À compléter : lien Google Play (bouton « Bientôt sur Google Play » dans `index.html`) et adresse de contact (commentaire `CONTACT` dans `index.html`).
